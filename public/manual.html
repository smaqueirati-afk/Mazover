Cómo manejar tu tienda

Guía paso a paso para administrar el sitio de MAZOVER: cargar productos, editar textos e imágenes, recibir consultas por WhatsApp y todo lo que podés cambiar vos mismo, sin tocar código.

01 Cómo funciona (en simple)

Tu tienda está formada por tres piezas que trabajan juntas. No necesitás entender la parte técnica para usarla, pero conviene saber qué hace cada una:

PiezaPara qué sirve
El sitio (mazover.vercel.app)Lo que ven tus clientes: home, catálogo, productos, carrito.
El panel (/admin)Donde vos cargás y editás TODO: productos, fotos, textos, precios, menú.
La base de datos (Supabase)Guarda toda la información. El panel escribe ahí y el sitio la muestra.
Lo más importanteTodo el contenido del sitio se edita desde el panel. Cada texto, foto, precio, color y sección es modificable sin programar. Lo que cambiás en /admin aparece en el sitio al instante.

02 Entrar al panel

  1. Entrá a https://mazover.vercel.app/admin/login
  2. Escribí tu email y contraseña de administrador.
  3. Tocá Ingresar. Vas a ver el panel con el menú lateral.
Cerrar sesiónAbajo del menú lateral tenés Cerrar sesión. Y Ver sitio ↗ abre la tienda en otra pestaña para revisar los cambios.
SeguridadNo compartas tu usuario. Solo las personas con acceso de administrador pueden modificar la tienda; el resto (clientes) nunca ve el panel.

03 Dashboard

Es la pantalla de inicio del panel. Te muestra de un vistazo:

  • Productos activos — cuántos se están mostrando en la tienda.
  • Productos sin stock — para saber qué reponer.
  • Variantes — combinaciones de color × talle cargadas.
  • Destacados — los que aparecen en la home.
  • Consultas — pedidos recibidos.

Desde acá también tenés accesos rápidos a “Nuevo producto”, Contenido, Menú y Configuración.

04 Productos

Es el corazón del panel. Un producto (ej. “Jean Relaxed”) puede tener varios colores, y cada color varios talles con su propio stock. Así funciona el cambio de color en la ficha del producto.

Crear un producto

  1. Menú → Productos → + Nuevo producto.
  2. Completá la pestaña Info y tocá Guardar producto. Recién ahí se habilitan las demás pestañas.
  3. Cargá Colores, después Stock, después Imágenes. Opcional: SEO.

Pestaña INFO

CampoQué es
NombreCómo se llama el producto.
SlugLa dirección web (se genera solo del nombre; podés dejarlo).
Descripción corta / completaLa corta aparece en la card; la completa en la ficha.
Categoría / CortePara los filtros del catálogo (Jeans, Straight, etc.).
ComposiciónEj. “100% algodón · 14.5 oz”.
Precio / Precio anteriorEl precio anterior se muestra tachado (para ofertas).
ActivoSi está destildado, el producto NO se ve en la tienda.
Destacado / Nuevo / Best sellerDestacado = aparece en la home. Nuevo/Best seller = etiqueta sutil.

Pestaña COLORES

Cada color tiene nombre, muestra de color (hex), SKU base y su propia galería y stock. Podés elegirlo de la paleta o cargarlo a mano. Quitar borra el color y sus fotos/stock.

Pestaña STOCK (matriz)

Una tabla color × talle. Escribí las unidades en cada celda y tocá Guardar stock. Reglas automáticas en la tienda:

  • Talle con stock 0 → aparece AGOTADO y no se puede elegir.
  • Todos los talles de un color en 0 → color agotado.
  • Stock 1–3 → aviso “¡Últimas unidades!”.

Pestaña IMÁGENES

  1. Elegí el color y tocá + Subir imagen.
  2. La primera imagen queda de portada (es la que se ve en el catálogo). Podés cambiarla con Portada.
  3. Repetí para cada color: al cambiar de color en la ficha, cambia toda la galería.
Fotos recomendadasVerticales (proporción 4:5), buena luz, fondo prolijo. Mínimo ~1200 px de ancho. La primera de cada color debe ser la mejor (es la portada).

05 Categorías, colores y talles

Son las listas que usan los productos y los filtros. Cada una tiene su sección en el menú:

  • Categorías — Jeans, Camisas, Chinos… (nombre, orden, activo).
  • Colores — paleta reutilizable (nombre + muestra de color) para asignar a los productos.
  • Talles — 38, 40, 42… Se usan en la matriz de stock.

En cada una podés agregar, editar y borrar filas y guardar. El orden define cómo aparecen.

Guía de talles (por categoría)

Menú → Guía de talles. Editá la tabla de medidas que se muestra en la ficha de producto (botón “Guía de talles”).

  1. + Nueva guía para crear una; asignala a una categoría (Jeans, Camisas…) o dejala “General”.
  2. Editá los encabezados (Talle, Cintura, Cadera, Largo…) y los valores de cada celda.
  3. + Fila / + Columna para agregar; la ✕ para quitar. Marcá Activa y Guardar guía.
Cómo se muestraCada producto usa automáticamente la guía de su categoría. Si esa categoría no tiene guía propia, usa la “General”.

06 Menú

07 Reels de Instagram

La sección “Mirá cómo se usan” de la home. Cada reel muestra un video/imagen de la marca y puede linkear a un producto.

  1. Menú → Reels.
  2. Pegá el link del reel de Instagram, subí un poster (miniatura) y, si querés, elegí un producto asociado.
  3. Marcá Activo y guardá.

08 Contenido del sitio

Acá editás cada texto e imagen de las secciones: el hero, la filosofía, “Hecho en Argentina”, las frases, el pie, las páginas La Marca y Hecho en Argentina, etc.

  1. Menú → Contenido.
  2. Está agrupado por sección (Home · Hero, Home · Filosofía, …). Cambiá el texto o la URL de imagen que quieras.
  3. Tocá Guardar todo el contenido (arriba). Los cambios se ven al instante en el sitio.
Ejemplos de lo que podés cambiar acáEl título del hero, la bajada, el texto de los botones, las 4 características, las especificaciones del denim, las frases de marca, el horario de atención, y todos los textos de las páginas internas.
ImágenesEn cada campo de imagen tenés un botón Subir imagen (se sube sola y muestra vista previa) y, debajo, el tamaño recomendado para esa foto (ej. hero vertical ~1600×2000, banda apaisada 1920×900). Subí la foto con esa proporción para que no quede recortada.

09 Configuración

Los datos generales de la marca. Menú → Configuración:

  • Marca — nombre y bajada.
  • Contacto — número de WhatsApp (con código de país, sin +, ej. 5493511234567), Instagram, email.
  • Paleta de colores — elegí entre 4 combinaciones coherentes (Heritage · Denim & Rojo, Índigo & Cobre, Noche & Acero, Campo · Verde & Óxido). Cada tarjeta muestra sus colores; la que elijas se aplica a todo el sitio al guardar (con ✓ la activa).
  • SEO global — título y descripción para Google.
Importante: el WhatsAppTodo el flujo de compra usa este número. Si está mal, las consultas no te llegan. Verificá que sea el correcto y probá el botón desde un producto.

10 Consultas

Registro de los pedidos/consultas. Vas a ver fecha, cliente, ítems, total estimado y estado. Te sirve para hacer seguimiento de lo que te llega por WhatsApp.

11 Cómo compra el cliente

Por ahora la compra es por WhatsApp (sin pago online todavía; la arquitectura ya está lista para sumar Mercado Pago más adelante).

  1. El cliente entra al producto, elige color y talle.
  2. Toca Comprar por WhatsApp (o suma varios al carrito y finaliza).
  3. Se abre WhatsApp con un mensaje ya armado: producto, color, talle y total estimado.
  4. Vos respondés y cerrás la venta.

12 Tareas frecuentes (recetas rápidas)

Agregar un producto nuevo

Productos → + Nuevo producto → Info + Guardar → Colores → Stock → Imágenes. Marcá Activo (y Destacado si querés que salga en la home).

Poner algo en oferta

En el producto, cargá el Precio anterior (mayor al precio actual). Se muestra tachado.

Marcar agotado un talle

Pestaña Stock → poné 0 en la celda del color/talle → Guardar stock.

Cambiar el número de WhatsApp

Configuración → Contacto → WhatsApp → Guardar.

Cambiar una foto o texto de la home

Contenido → buscá la sección → editá el texto o la URL de imagen → Guardar todo el contenido.

Cambiar la paleta de colores

Configuración → Paleta de colores → tocá una de las 4 tarjetas → Guardar cambios. Cambia toda la tienda al instante.

Editar la guía de talles

Menú → Guía de talles → elegí la guía (o + Nueva guía y asignale la categoría) → editá celdas / + Fila / + Columna → Guardar guía.

Agregar otro administrador

En Supabase → Authentication → Add user (con “Auto Confirm”) → después, en SQL Editor: update public.profiles set is_admin = true where email = 'EL-EMAIL';

13 Problemas comunes

SíntomaSolución
“Invalid login credentials” al entrarEl usuario/contraseña no coinciden. En Supabase → Authentication, recreá el usuario con Auto Confirm User tildado y una contraseña conocida.
El panel dice “Conectá Supabase”Faltan las variables de entorno en Vercel (URL y anon key). Se cargan en Vercel → Settings → Environment Variables.
“Sin permisos” después de entrarFalta marcar tu usuario como admin: update public.profiles set is_admin = true where email = 'TU-EMAIL';
Una foto no subeQue sea imagen (jpg/png/webp) y no muy pesada. Revisá tu conexión y reintentá.
Cambié algo y no se veRefrescá la página del sitio. Si editaste contenido, asegurate de haber tocado “Guardar”.
